# MCTI · 麦当劳人格类型指标

> 用你吃过的麦当劳，测出你是哪种人。
> 一个零依赖、单文件、复古开心乐园餐玩具风格的趣味人格测评 + 今日点餐推荐工具。

---

## 这是什么

MCTI（McDonald's Character Type Indicator，麦当劳人格类型指标）是一个**粉丝向趣味测评**：

- 读取你的麦当劳历史点单数据，按 **4 个维度** 打出人格画像；
- 映射出 **16 种人格类型**（风格涵盖高冷、快乐小狗、傲娇、无厘头、丧系、小狗塑、小猫塑等，全部正面导向）；
- 结合 **当前时段** 给你一份「今日点餐推荐组合」+ 理由 + 今日宜忌 + 本命开心乐园餐玩具。

纯前端单文件 `index.html`，**无需任何构建、无需联网依赖（菜单图片走远程 CDN，断网时自动降级为文字占位）**，双击即可在浏览器 / 手机打开。

---

## 四维人格模型

| 维度 | 极 A | 极 B | 说明 |
| --- | --- | --- | --- |
| 麦门忠诚度 | M 麦门信徒 | W 浪系尝鲜 | 是否长期点同一款招牌 |
| 出没时段 | A 早鸟型 | N 夜猫型 | 下单多集中在清晨还是深夜 |
| 花钱哲学 | F 持家型 | L 阔气型 | 历史订单均价高低 |
| 甜咸偏好 | S 甜党 | V 咸香派 | 点单偏向甜品还是咸口主餐 |

四轴组合 → 16 种人格（如 `MAFV` = 麦门忠诚 + 早鸟 + 持家 + 咸香 = **「晨光麦门守门员」高冷型**）。

## 使用方法

1. 直接双击 `index.html` 在浏览器打开（手机端也适配）。
2. 默认已内置一份示例订单数据并自动测算。
3. 想用自己的数据：把页面底部文本框里的 JSON 换成你自己的（支持 mcd-mcp `order-list` 原始返回结构），点「用这份数据测算」即可。
   - 示例订单字段：`{ date, hour, store, name, amt }`

---

## 部署到 GitHub Pages（可选）

1. 在 GitHub 新建一个仓库（例如 `mcti`）。
2. 把本仓库的 `index.html` 和 `README.md` **直接拖到网页端的 Upload files** 上传（无需命令行）。
3. 仓库 → **Settings → Pages → Source 选 `main` 分支 / `(root)`** → Save。
4. 约 1 分钟后访问 `https://<你的用户名>.github.io/<仓库名>/` 即可公开展示。

> 只想自己看的话，不上传、本地双击 `index.html` 也完全够用。

## 数据来源

- 人格分析所用的示例订单，来自 `mcd-mcp` 的 `order-list` 接口（已脱敏为分析字段）。
- 推荐页单品节选自 `mcd-mcp` 的 `query-meals` 实时菜单（含图片与现价快照）。
- 工具运行时不依赖任何外部接口；上述数据已内嵌为种子数据，可随时替换。
